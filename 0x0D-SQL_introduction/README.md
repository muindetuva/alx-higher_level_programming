# SQL Introduction

This project contains MySQL scripts for creating and deleting databases,
creating and inspecting tables, inserting and updating rows, filtering and
aggregating records, and computing temperature statistics. The scripts are
designed to be piped to the `mysql` command exactly as documented by each
exercise.

The advanced scripts convert database text to `utf8mb4`, calculate average
temperatures by city, identify the hottest cities in summer, and report each
state's maximum temperature.
